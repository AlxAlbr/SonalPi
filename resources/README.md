# Ressources de distribution

Les icônes `icons/sonalpi2.{png,ico,icns}` reprennent les ressources graphiques
existantes de SonalPi1. Le dossier V1 n'est pas modifié. L'identité de distribution
V2 reste distincte : produit SonalPi2, appId `org.sonalpi.sonalpi2`, exécutable et
entrée desktop `sonalpi2`.

Les sources de démonstration `CorpusTest/` sont copiées séparément par
`electron-builder`, hors de l'archive applicative.

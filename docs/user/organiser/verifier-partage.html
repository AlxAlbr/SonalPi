Organiser et exporter

Vérifier les données avant diffusion

Avant de transmettre un fichier, vérifiez qu’il contient les informations utiles à son destinataire. Envoyer des entretiens à un collègue du même projet et diffuser des extraits dans une publication ne répondent pas au même besoin.

Partager ne signifie pas nécessairement pseudonymiser. Un échange non pseudonymisé peut être adapté au sein d’un projet de recherche, avec des personnes autorisées à consulter ces données. Le choix dépend des destinataires, de l’usage prévu et des engagements pris pour l’enquête.

Choisir le contenu selon le destinataire

Commencez par préciser ce que la personne doit pouvoir faire : relire un entretien, comparer des extraits ou reprendre une analyse dans un autre logiciel. Ne joignez que les informations nécessaires à cet usage.

  • Pour une relecture, choisissez un format de lecture ou un document combiné.
  • Pour poursuivre l’analyse dans QualCoder, utilisez le transfert dédié, qui reprend le texte original sans pseudonymisation.
  • Décidez séparément si les notes, variables, commentaires ou enregistrements sont utiles à cet échange.

Choisir de pseudonymiser ou non le texte

Dans les formats qui le proposent, vérifiez la case Appliquer la pseudonymisation. Décochez-la si vous souhaitez transmettre le texte original. Ne vous fiez pas au réglage initial : il varie selon le format.

Si l’échange demande un texte pseudonymisé, préparez les remplacements dans l’outil de pseudonymisation, puis activez cette option à l’export. Consultez le rapport lorsqu’il est proposé et relisez le résultat : le contexte peut encore permettre de reconnaître une personne.

Le module de pseudonymisation traite le texte ; il ne transforme pas les enregistrements audio ou vidéo. Le choix de joindre ces fichiers est indépendant du choix de pseudonymiser la transcription.

Vérifier les fichiers à transmettre

Ouvrez les fichiers produits et examinez le dossier d’envoi, plutôt que de vous limiter aux cases choisies dans SonalPi.

  1. Entretiens et passages. Retrouvez-vous les sources attendues, dans leur bonne version ? Le texte est-il original ou pseudonymisé comme vous le souhaitiez ?
  2. Informations d’accompagnement. Vérifiez les titres, noms de fichiers, notes, commentaires et auteurs, libellés de thèmes et valeurs de variables. Leur présence peut être utile et voulue ; assurez-vous qu’elle convient au destinataire.
  3. Contenu propre au format. Un fichier HTML conserve les commentaires sans les afficher. Un fichier SONAL complet peut conserver des variables privées. Les exclusions des formats de lecture ne s’appliquent pas indistinctement à toutes les sorties : consultez le contenu de chaque format et les éléments transférés vers QualCoder.
  4. Enregistrements. Si vous avez demandé leur copie dans un lot HTML, ils restent les originaux, même avec une transcription pseudonymisée. Joignez-les seulement si cet envoi est prévu ; sinon, préparez un dossier sans ces fichiers.
  5. Fichiers annexes. Examinez aussi l’index du lot et les rapports enregistrés. Le rapport de pseudonymisation sert au contrôle des remplacements ; il n’a pas à accompagner systématiquement les documents transmis.

Par exemple, un collègue chargé de relire les entretiens dans le même projet peut avoir besoin des noms réels et de l’audio. Pour transmettre uniquement des extraits pseudonymisés à un autre destinataire, préparez plutôt les textes nécessaires sans joindre automatiquement les enregistrements, rapports ou fichiers de travail.

Faire une dernière vérification avant l’envoi

  • Le destinataire et le moyen d’envoi conviennent-ils aux données partagées et aux règles du projet ?
  • Le dossier contient-il seulement les fichiers prévus, sans ancienne version ni ajout involontaire ?
  • Le destinataire saura-t-il ce qu’il reçoit : textes originaux ou pseudonymisés, sélection complète ou partielle, présence ou absence des médias ?

Gardez votre corpus de travail séparé de ces copies. Si vous corrigez un élément dans SonalPi après l’export, produisez de nouveaux fichiers : les copies déjà exportées ne se mettent pas à jour.

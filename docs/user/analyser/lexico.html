Explorer les mots avec Lexico

Lexico dresse la liste des mots présents dans les transcriptions, compte leurs occurrences et permet de les relire dans leur contexte. Il aide à repérer des expressions récurrentes et à comparer leur présence dans les entretiens.

Vous pouvez commencer avec votre propre corpus dès qu’il contient une transcription. Aucun thème, cas ou exercice préalable n’est nécessaire. Si vous préférez essayer sans utiliser vos données, vous pouvez ouvrir une copie d’un corpus exemple.

Ouvrir Lexico et lire l’index

  1. Ouvrez votre corpus, puis Analyser et interpréter → Lexico.
  2. Attendez la fin de l’analyse. L’index se charge à l’ouverture de l’outil ; vous n’avez pas à sélectionner un thème pour le lancer.
  3. Pour une première exploration, vérifiez les filtres à gauche. Le badge Sans restriction indique qu’un onglet ne retire aucun mot. Si vous souhaitez repartir sans vos restrictions précédentes, utilisez Réinitialiser la sélection dans le bilan.
  4. Choisissez une forme dans le tableau pour lire ses occurrences.

Le tableau présente trois colonnes :

  • Forme : le mot ou le libellé sous lequel les occurrences sont réunies.
  • Occurrences : combien de fois cette forme apparaît dans les matériaux retenus.
  • Entretiens : le nombre d’entretiens distincts contenant au moins une de ces occurrences.

Par exemple, une ligne indiquant 15 occurrences dans 3 entretiens ne signifie pas que le mot apparaît cinq fois dans chacun : un seul entretien peut en contenir la majorité. Cliquez sur un en-tête pour trier le tableau ; un nouveau clic inverse le sens du tri.

Les paroles des enquêteurs sont exclues au départ, d’après le rôle renseigné dans Locuteurs. Cochez Inclure les paroles des enquêteurs à gauche si vous souhaitez aussi analyser leurs questions et interventions.

Lire les concordances et retrouver la source

  1. Cliquez sur le nom d’une forme ou sur sa ligne dans le tableau. La section Concordances s’ouvre en dessous.
  2. Lisez les mots qui entourent chaque occurrence mise en évidence et le titre de son entretien.
  3. Cliquez sur une concordance pour ouvrir l’entretien à cette position et relire un passage plus large.
  4. Pour revenir aux résultats, utilisez le retour à l’analyse proposé en haut de la fenêtre lorsqu’il est affiché, ou rouvrez Analyser et interpréter → Lexico.

Les petites cases du tableau servent à sélectionner des formes pour les traitements lexicaux, pas à ouvrir les concordances. La croix Fermer les concordances ferme ce détail sans retirer la forme de l’index.

Le contexte n’est pas ajouté au comptage. Il peut dépasser les passages retenus par un filtre de thème ou de cas. Seule l’occurrence mise en évidence est comptée ; les mots voisins servent à comprendre son emploi.

Une fréquence ne dit pas à elle seule ce qu’un mot signifie ni son importance pour l’enquête. Relisez plusieurs emplois : le même mot peut désigner des choses différentes, et un sujet peut être exprimé avec plusieurs mots.

Ajuster le tableau sans changer les matériaux

  • Rechercher une forme réduit les lignes visibles aux formes contenant la suite saisie. Ce champ ignore les majuscules et les accents pour retrouver les lignes ; il ne fusionne pas leurs comptes.
  • Fréquence minimale masque les formes dont le nombre d’occurrences est inférieur au seuil choisi. Remettez 1 pour retrouver les formes rares.
  • Afficher les nombres, décoché au départ, rend visibles les lignes constituées de nombres.

Ces réglages s’appliquent immédiatement au tableau visible. Ils ne changent ni les transcriptions ni les matériaux annoncés dans le bilan. Celui-ci peut donc indiquer davantage de formes que le nombre de lignes actuellement affichées.

La recherche du tableau n’est pas la recherche de mots dans les transcriptions : elle retrouve les formes déjà présentes dans cet index, après les filtres et les traitements. Pour retrouver un tableau plus large, videz aussi ce champ et vérifiez le seuil et les nombres.

Choisir les textes et les paroles à analyser

Les filtres de gauche choisissent les matériaux analysés. Ils modifient immédiatement les comptes de l’index déjà chargé. Si le panneau est masqué, cliquez sur Afficher les filtres.

OngletCe qui est retenu lorsque vous faites un choix
EntretiensLes mots des entretiens choisis.
VariablesLes entretiens portant les réponses choisies, ou les paroles des locuteurs portant ces réponses si la variable concerne les locuteurs. Non renseigné désigne une réponse absente, pas une réponse négative.
PersonnesLes paroles des personnes choisies, selon leurs associations aux locuteurs. Les options Locuteurs sans personne associée et Passages sans locuteur permettent d’inclure explicitement ces autres paroles.
ThèmesLes mots qui rencontrent les passages codés avec au moins un thème choisi. Cochez les sous-thèmes souhaités : choisir leur parent ne les sélectionne pas automatiquement.
CasLes mots présents dans les matériaux des cas choisis. L’onglet apparaît seulement si le corpus contient des cas.

Dans une liste, plusieurs choix retiennent l’un ou l’autre ; entre plusieurs filtres, les conditions doivent être satisfaites ensemble. Choisir une personne et un thème retient ainsi les mots de cette personne dans les passages codés avec ce thème, pas l’ensemble de ses paroles ajouté à tous les mots du thème.

Sans restriction, tout cocher ou tout décocher ?

  • Sans restriction : cet onglet ne retire aucun mot. Les cases peuvent toutes être décochées sans que les matériaux soient exclus.
  • Tout cocher : sélectionne explicitement les éléments actuellement dans la liste. De futurs entretiens ne seront pas ajoutés automatiquement à ce choix après actualisation.
  • Tout décocher : conserve un filtre avec une sélection vide ; cela peut donc ne laisser aucun résultat.
  • Retirer ce filtre : revient à Sans restriction pour l’onglet ou la variable concernée.

Cocher toutes les personnes ne couvre pas les paroles des locuteurs sans personne associée. De même, tous les thèmes ou tous les cas ne couvrent pas les passages qui n’en ont aucun. Pour analyser sans ces restrictions, retirez les filtres plutôt que de tout cocher.

Changer d’onglet ou masquer les filtres ne les retire pas. Les badges et Voir les critères dans le bilan permettent de les retrouver. Réinitialiser la sélection retire les filtres de matériaux et rétablit l’exclusion initiale des enquêteurs ; cela ne vide pas la recherche du tableau, ne remet pas sa fréquence minimale à 1 et ne retire pas les traitements lexicaux.

Comprendre ce qui est compté

Lexico réunit les différences de majuscules, mais conserve les accents et les graphies. Les formes singulières, plurielles ou conjuguées ne sont pas ramenées automatiquement à un même mot. Les apostrophes et les traits d’union à l’intérieur d’un mot peuvent faire partie de sa forme.

L’index utilise le texte pseudonymisé. Un pseudonyme remplaçant une entité compte comme une seule unité, même s’il contient plusieurs mots ; les mots remplacés ne sont pas comptés à cet emplacement. Les noms laissés en clair restent toutefois dans le texte analysé. Contrairement à Tri et synthèse, Lexico ne propose pas de bascule vers le texte original.

Des traitements lexicaux peuvent déjà être enregistrés dans votre corpus : les mots outils écartent des formes, les regroupements réunissent plusieurs graphies sous un libellé commun et les concaténations réunissent des formes successives. Le bouton Traitement lexical permet de consulter ces réglages. Ils influencent les comptes sans réécrire les paroles des entretiens.

Pour modifier ces règles, consultez Adapter le traitement lexical : écarter des mots, regrouper des formes, réunir une expression et revenir sur vos choix.

Lorsqu’un regroupement est actif, les concordances conservent les mots effectivement présents, même si le tableau les classe sous un autre libellé. Avant de comparer deux résultats, vérifiez donc les matériaux choisis et les traitements, pas seulement le nom de la forme.

Lire le bilan et actualiser

Le bilan distingue les entretiens avec résultats, les occurrences, les formes et les critères appliqués. Il décrit les matériaux retenus après les filtres et les traitements, avant les restrictions d’affichage du tableau. Un entretien sans occurrence retenue ne compte pas comme un entretien avec résultats.

Si aucune forme n’est affichée, vérifiez d’abord le champ de recherche, la fréquence minimale et l’affichage des nombres, puis les badges des filtres, les paroles d’enquêteur et les traitements actifs.

Après une correction des transcriptions ou de la pseudonymisation, utilisez Actualiser. L’outil recharge aussi l’index à son ouverture lorsqu’il est absent ou signalé comme périmé. Si l’avertissement Les sources ont changé apparaît, l’ancien résultat reste lisible, mais son export est bloqué : actualisez avant d’interpréter les comptes ou de rejoindre une ancienne position dans le texte.

Si Analyse incomplète est affiché, dépliez l’avertissement, examinez les éléments indiqués puis actualisez après leur résolution. Le résultat disponible reste consultable ; l’export reste désactivé. Si un filtre utilise un cas qui a disparu, choisissez Retirer le filtre Cas seulement si vous souhaitez élargir la sélection.

Sur Nextcloud ou GitLab, l’index utilise les données disponibles sur votre poste et le texte en mémoire de l’entretien ouvert. Il ne publie pas vos corrections. Pour reprendre des changements d’équipe, actualisez le corpus lorsque vous êtes connecté, puis Lexico.

Exporter le tableau dans un tableur

  1. Vérifiez les matériaux et les traitements, puis les lignes affichées : recherche, fréquence minimale, nombres et tri.
  2. Assurez-vous que l’analyse est à jour et sans problème signalé ; sinon, consultez le bilan et actualisez.
  3. Cliquez sur Exporter CSV ou Exporter TSV, puis choisissez le nom et l’emplacement du fichier.
  4. Ouvrez le fichier et contrôlez son contenu avant de le partager.

L’export reprend les lignes du tableau actuellement affichées, dans leur ordre, avec les colonnes Forme, Occurrences et Entretiens. Cocher des formes pour un traitement ne limite pas l’export à ces seules cases. Les concordances et les textes des entretiens ne sont pas ajoutés.

Le fichier ajoute une date, les sources demandées, le résumé des critères, le nombre de traitements et les paramètres d’affichage. Les noms des personnes choisies et le détail des variables privées sont masqués dans ce résumé. Cela ne retire pas les noms qui figureraient dans une forme, un titre de source ou un autre libellé libre : contrôlez la sortie selon son destinataire.

Si le tableur demande des options d’import, choisissez UTF-8 et le séparateur virgule pour le CSV, ou tabulation pour le TSV. Ce CSV utilise la virgule, contrairement à l’export de la table de données du corpus qui utilise le point-virgule.

En local, le dossier proposé est resultats/lexico/ dans le corpus. Pour un corpus distant, SonalPi propose Documents sur votre poste : le fichier n’est pas envoyé automatiquement à Nextcloud ou GitLab. L’export conserve une sortie de lecture, pas une sauvegarde complète ni une analyse qui se mettra à jour dans le tableur.

Pour comparer les fréquences avec prudence et garder une trace de vos choix, consultez Vérifier et interpréter les résultats.

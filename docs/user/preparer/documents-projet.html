Réunir les documents du projet

Rassemblez avec votre corpus les documents utiles à l’enquête : guide d’entretien, consignes de correction, documents de consentement ou comptes rendus de réunion. Vous pourrez les retrouver sans quitter SonalPi.

SonalPi conserve les fichiers dans leur format d’origine et ne modifie pas leur contenu. Vous pouvez les consulter, en enregistrer une copie ou les ouvrir dans leur application habituelle pour les modifier.

Ajouter un document ici ne crée pas d’entretien et ne transforme pas son contenu en transcription. Pour analyser le texte d’un entretien, utilisez plutôt l’import d’une transcription.

Retrouver les documents du corpus

  1. Ouvrez votre corpus, puis cliquez sur Préparer et suivre dans la barre supérieure.
  2. Dans les onglets à icônes de gauche, choisissez Documents du projet. Le survol d’une icône affiche son nom.
  3. Cliquez sur un document dans la liste de gauche : sa fiche et, si disponible, son aperçu apparaissent à droite.

Ces documents appartiennent au corpus courant. L’onglet voisin Documents exemples contient les fichiers fournis avec SonalPi, pas vos fichiers personnels. Ces exemples portent actuellement la mention À venir. et ne constituent pas encore des modèles rédigés.

Dans un corpus local, vos documents sont rangés dans le sous-dossier DocsPrepaProjet du corpus. Le bouton Ouvrir ce dossier permet de le retrouver dans le gestionnaire de fichiers. Il est disponible même si vous n’avez encore ajouté aucun document.

Ajouter un document dans un corpus local

  1. Ouvrez le dossier de destination dans la liste, ou restez au premier niveau.
  2. Cliquez sur Ajouter un fichier.
  3. Choisissez le document dans le sélecteur de fichiers et confirmez.
  4. Vérifiez le message d’ajout et le nom du fichier dans la liste.

Le fichier est copié dans le dossier affiché. L’original reste à son emplacement initial. Contrairement à l’audio associé aux entretiens, il fait donc partie du dossier du corpus et de sa sauvegarde ZIP locale.

Vous pouvez aussi glisser un ou plusieurs fichiers depuis votre gestionnaire de fichiers vers l’onglet actif Documents du projet. Les fichiers vont dans le dossier affiché au début du dépôt. Déposer un dossier complet n’est pas pris en charge : créez les sous-dossiers voulus puis ajoutez leurs fichiers.

Un fichier existant n’est pas remplacé par un ajout homonyme. Avec Ajouter un fichier, un nom libre comme Guide-2.docx peut être utilisé ; si le sélecteur s’ouvre à nouveau, sélectionnez de nouveau le fichier à copier. Avec le glisser-déposer, le fichier homonyme est refusé. Lors d’un dépôt de plusieurs fichiers, certains peuvent être ajoutés et d’autres refusés : relisez le message et la liste.

Ranger les documents dans des dossiers

Vous pouvez par exemple créer les dossiers Méthode, Consentements et Réunions.

  1. Dans le dossier qui doit accueillir le nouveau sous-dossier, cliquez sur Nouveau dossier.
  2. Renseignez Nom du nouveau dossier, puis cliquez sur Créer le dossier.
  3. Cliquez sur le dossier créé pour y entrer, puis ajoutez vos fichiers.

Les dossiers précèdent les documents, par ordre alphabétique. Dans un sous-dossier, le chemin Documents › Méthode › … permet de revenir aux parents. Les deux onglets documentaires conservent chacun leur dossier pendant la session ; changer de corpus les ramène au premier niveau.

Pour déplacer, renommer ou supprimer un fichier ou un dossier, utilisez Ouvrir ce dossier et faites l’opération dans votre gestionnaire de fichiers, puis revenez dans SonalPi et cliquez au besoin sur Actualiser. SonalPi ne propose pas ces opérations dans la liste. Les possibilités de récupération après suppression dépendent de votre système et de vos sauvegardes.

Consulter un document et comprendre les aperçus

FormatConsultation dans SonalPi
TXT, Markdown (.md), CSVTexte brut. Le Markdown n’est pas mis en forme et le CSV n’est pas présenté comme un tableur.
PNG, JPG, JPEG, GIF, WebPImage en lecture seule.
PDFUne page à la fois, avec Page précédente, Page suivante, Agrandir et Réduire.
Word (.docx, .doc), ODT, RTF, HTML et autres formatsFiche du fichier, sans aperçu intégré. Utilisez l’application habituelle pour consulter le contenu.

L’aperçu PDF sert à lire, pas à modifier le document, remplir ses formulaires ou utiliser ses liens et pièces jointes. Ouvrez le fichier dans une application adaptée pour ces usages.

Un fichier trop volumineux peut rester dans la liste sans aperçu. Cela ne signifie pas qu’il n’a pas été conservé : ouvrez-le ailleurs ou utilisez Enregistrer une copie. Si le contenu n’est pas reconnu comme le format annoncé ou si le texte ne peut pas être lu, un message remplace l’aperçu.

Ouvrir, modifier ou copier un fichier

  • Ouvrir, ou un double-clic sur un document local du projet, lance l’application habituelle du poste. Si vous y enregistrez vos modifications dans le même fichier, vous modifiez la copie présente dans le corpus.
  • Afficher dans le dossier sélectionne le document dans le gestionnaire de fichiers. Pour choisir une autre application, utilisez alors le menu Ouvrir avec de votre système.
  • Enregistrer une copie enregistre le fichier d’origine, sans conversion, à l’emplacement de votre choix.

Le document source, la copie ajoutée au corpus et les copies enregistrées ailleurs ne se mettent pas à jour entre eux. Si vous souhaitez faire évoluer le document du projet, ouvrez bien celui du corpus. Après une modification externe, revenez dans SonalPi puis utilisez Actualiser si nécessaire.

Consulter les documents d’un corpus distant

Sur Nextcloud, SonalPi consulte les documents sur le serveur. Vous pouvez parcourir les dossiers, afficher les aperçus disponibles et enregistrer une copie sur votre poste. L’ajout et la réorganisation ne se font pas depuis SonalPi.

  1. Dans Documents du projet, ouvrez le dossier concerné.
  2. Cliquez sur Organiser ce dossier dans Nextcloud.
  3. Dans le navigateur, connectez-vous si nécessaire, puis ajoutez, déplacez ou modifiez les documents selon vos droits et les applications disponibles sur le serveur.
  4. Revenez dans SonalPi et cliquez sur Actualiser.

Si le dossier de documents n’existe pas encore, créez DocsPrepaProjet dans le dossier du corpus sur Nextcloud. Sans connexion, la dernière liste affichée peut rester visible, mais cela ne garantit pas l’accès au contenu des documents. Les Documents exemples, fournis avec l’application, restent consultables.

Sur GitLab, les documents du projet ne sont pas disponibles dans cet outil. Les documents exemples restent distincts et accessibles.

Si un document n’apparaît plus

  • Vérifiez le corpus et le sous-dossier affichés, puis cliquez sur Actualiser.
  • Si un dossier a été supprimé ailleurs, la liste remonte au premier parent encore disponible.
  • En local, ouvrez le dossier pour vérifier que le fichier y est réellement présent. Les fichiers cachés, temporaires et raccourcis vers d’autres emplacements ne sont pas tous affichés.
  • En cas de message d’erreur, vérifiez vos accès et, pour Nextcloud, la connexion. Une ancienne liste restée à l’écran n’est pas une confirmation que les fichiers sont toujours disponibles.

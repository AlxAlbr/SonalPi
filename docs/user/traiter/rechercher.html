Rechercher dans les entretiens

Retrouvez un mot ou une expression dans les transcriptions, puis relisez les passages dans leur contexte. Vous pouvez chercher dans l’ensemble du corpus, ou seulement dans l’entretien ouvert. La recherche ne demande ni codage préalable ni enregistrement audio.

Ces deux recherches se lancent dans Importer et traiter, avec le même raccourci : Ctrl + F sous Windows/Linux, Commande + F sous macOS. Le niveau affiché détermine où vous cherchez.

Choisir où chercher

Vous êtes au niveau…Ctrl + F / Commande + FCe que vous pouvez faire
CorpusOuvre le panneau Recherche dans les transcriptions du corpus.Lire des extraits regroupés par entretien, utiliser Mot entier et ouvrir un passage.
EntretienOuvre la boîte de recherche dans la transcription affichée.Parcourir les occurrences et, si l’entretien est modifiable, remplacer du texte.

Les deux recherches portent sur les paroles transcrites, pas sur les titres d’entretien, les noms des locuteurs affichés au-dessus des tours, les notes, les commentaires ou les valeurs des variables. Un nom n’est trouvé que s’il figure aussi dans les phrases. Pour les autres contenus, utilisez la recherche de leur outil, par exemple Notes ou Personnes.

Chercher dans l’ensemble des entretiens

  1. Dans Importer et traiter, revenez au niveau Corpus si un entretien est ouvert. Ce retour ferme l’entretien.
  2. Appuyez sur Ctrl + F ou Commande + F. La recherche n’a pas de bouton dédié dans la barre d’icônes du corpus.
  3. Saisissez le mot ou l’expression dans Rechercher dans le corpus.
  4. Cliquez sur Rechercher ou appuyez sur Entrée, puis attendez le résultat.
  5. Si nécessaire, cochez Mot entier. Ce changement relance la recherche : « le » peut alors trouver « le », mais pas la fin de « parle ».

Le panneau annonce un nombre d’occurrences et d’entretiens contenant un résultat, puis présente les extraits par entretien. Une occurrence est une correspondance trouvée dans le texte ; plusieurs peuvent appartenir à la même phrase ou au même passage.

Sans Mot entier, une recherche peut trouver une partie de mot. Par exemple, « bénévol » peut retrouver « bénévole » et « bénévolat » s’ils figurent dans les transcriptions. L’extrait peut mettre en évidence le mot complet contenant la partie recherchée.

Si vous changez les mots saisis, cliquez de nouveau sur Rechercher : la liste n’est pas recalculée au fil de cette saisie. Le bouton Effacer, lorsqu’il est affiché sous les résultats, retire la requête et sa liste sans effacer les transcriptions. La croix Fermer la recherche ou Échap quitte le panneau.

Ouvrir un résultat et relire le contexte

  • Dans la liste d’extraits : cliquez sur un extrait pour ouvrir l’entretien à la position trouvée.
  • Sur les cartes : les petits marqueurs de recherche repèrent les occurrences le long du texte. Cliquez sur l’un d’eux pour afficher son extrait à gauche, sans ouvrir l’entretien.
  • Depuis cet extrait : cliquez sur Ouvrir l’entretien ici → pour rejoindre le passage dans la transcription.

Les marqueurs indiquent une place dans le texte, pas une seconde de l’enregistrement. Leur proximité ne prouve pas que deux paroles ont été prononcées au même moment. L’extrait montre seulement un contexte court : ouvrez la source pour interpréter ce qui a été dit.

Pour revenir à l’ensemble, utilisez Retour au niveau Corpus ou Corpus dans le fil de navigation. Relancez la recherche si vous avez corrigé le texte entre-temps. Pour mettre en évidence le mot dans l’entretien ouvert, lancez aussi sa propre recherche avec Ctrl + F ou Commande + F.

Chercher dans l’entretien ouvert

  1. Ouvrez l’entretien, puis appuyez sur Ctrl + F ou Commande + F.
  2. Saisissez le mot ou l’expression dans le champ Rechercher…. Ici, les résultats se mettent à jour pendant la saisie et les occurrences sont mises en évidence dans le texte.
  3. Utilisez les flèches Occurrence précédente et Occurrence suivante pour les parcourir. Entrée dans le champ de recherche passe au résultat suivant ; après le dernier, vous revenez au premier.
  4. Lisez le compteur : 2/5 signifie que vous consultez la deuxième occurrence sur cinq ; 0/0 signifie qu’aucune correspondance n’est trouvée pour cette recherche.

Si le champ de recherche est encore vide et que vous avez sélectionné des mots dans la transcription, l’ouverture de la boîte peut reprendre cette sélection comme requête. Vérifiez toujours le texte affiché dans le champ.

La boîte de l’entretien ne propose pas l’option Mot entier : une courte suite de lettres peut aussi être trouvée au milieu d’un mot. Fermez la boîte avec sa croix ou avec Échap depuis l’un de ses champs. Fermer la recherche retire les surlignages, pas le texte.

Remplacer du texte avec prudence

Le remplacement concerne uniquement l’entretien ouvert. Il n’existe pas de remplacement global depuis le panneau de recherche du corpus. En lecture seule, les commandes de remplacement sont masquées, mais la recherche reste consultable.

  1. Recherchez le texte à corriger et relisez les occurrences.
  2. Renseignez Remplacer par….
  3. Cliquez sur Remplacer pour modifier l’occurrence courante, ou sur Tout pour modifier toutes les occurrences trouvées dans cet entretien.
  4. Relisez les phrases corrigées et vérifiez l’état d’enregistrement avant de fermer l’entretien.

Tout applique immédiatement le remplacement, sans confirmation supplémentaire. Une recherche courte peut aussi modifier des morceaux de mots ; un même nom peut désigner plusieurs personnes. Un champ de remplacement vide supprime le texte trouvé. Préférez les corrections une par une si les contextes diffèrent.

Pour revenir sur un remplacement récent, utilisez Édition → Annuler ou Ctrl + Z / Commande + Z dans l’éditeur. Le remplacement par Tout forme une seule action d’annulation. Cela ne remplace pas une sauvegarde ni ne garantit une annulation après fermeture de l’entretien.

Remplacer un nom dans le texte est une correction de la transcription, pas une règle de pseudonymisation. Pour conserver l’original et décider des remplacements à la diffusion, utilisez la pseudonymisation.

Adapter les mots recherchés

  • Majuscules et minuscules : elles ne distinguent pas les résultats. « LYON » peut retrouver « Lyon ».
  • Accents : ils comptent. « benevole » ne remplace pas la recherche de « bénévole ».
  • Expression : les mots et les espaces doivent se suivre comme dans le texte. Une expression coupée entre deux paragraphes n’est pas trouvée comme une seule occurrence.
  • Variantes : les pluriels, les synonymes et les fautes de transcription ne sont pas regroupés automatiquement. Essayez plusieurs formulations.
  • Caractères spéciaux : la recherche lit ce que vous saisissez. Une étoile ou les mots « ET » et « OU » ne construisent pas une recherche combinée.

Ces recherches lisent le texte d’origine conservé dans la transcription. Elles ne cherchent pas à la place de celui-ci dans les pseudonymes seulement affichés par les règles de pseudonymisation. Les résultats peuvent donc montrer des noms réels : ne les diffusez pas sans contrôle du contenu.

Vérifier la portée et l’actualité des résultats

La recherche du corpus lit les entretiens disponibles au moment du lancement. Elle n’est pas un suivi permanent des corrections : après une modification ou un nouvel import, relancez-la. Une liste conservée à l’écran n’est pas nécessairement à jour.

L’absence de résultat ne signifie pas forcément que le sujet est absent. Vérifiez l’orthographe et les accents, essayez d’autres formulations et relancez la recherche si vous avez modifié les transcriptions.

Sur un corpus Nextcloud ou GitLab, la recherche du corpus utilise la copie disponible sur votre poste ; elle n’effectue pas une nouvelle lecture de chaque transcription sur le serveur à chaque requête. Si vous êtes connecté, utilisez Actualiser dans le corpus avant de rechercher des changements récents. Hors ligne, les résultats éventuels ne garantissent ni l’accès à toutes les sources ni leur actualité sur le serveur.

Dans l’entretien, la recherche suit les changements du texte affiché, mais ne remplace pas les règles d’enregistrement et de publication du corpus. Consulter une occurrence ne donne pas de droit de modification supplémentaire.

Une fréquence de mots n’est pas une conclusion sur leur importance. Relisez les passages en tenant compte de la personne qui parle et du contexte de l’entretien ; un même thème peut être exprimé sans le mot recherché.

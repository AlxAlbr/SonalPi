# Tri et synthèse

**Tri et synthèse** réunit les passages de plusieurs entretiens sans modifier le corpus.
L’outil est accessible dans l’espace **Analyser et interpréter**, onglet **Tri et synthèse** :
ses critères occupent la colonne de gauche, les résultats la colonne de droite.

1. Choisissez au moins un thème ou un cas dans le panneau de critères.
2. Ajoutez si besoin des entretiens, variables ou personnes.
3. Cliquez sur **Calculer**.
4. Utilisez **Vue d’ensemble** pour voir la répartition dans les transcriptions, ou
   **Extraits** pour lire et copier les passages.

La vue d’ensemble représente la progression dans la transcription, et non la durée audio.
Cliquer sur une zone affiche son détail. L’action **Ouvrir dans l’entretien** permet ensuite
de revenir à la source exacte.

Le texte est pseudonymisé par défaut. Le choix **Texte original** peut afficher des identités ;
il s’applique aussi à la copie et à l’export TXT.

Si les sources ou les critères changent, le résultat précédent est signalé comme périmé.
Il reste lisible, mais doit être actualisé avant la navigation ou l’export. Une source
indisponible est nommée et rend le résultat incomplet ; les autres entretiens restent
consultables.

Renseigner la base de données

L’onglet base de données vous permet de saisir les informations relatives au répondant directement en cours de lecture.

Vous pouvez choisir une modalité existante ou la saisir directement dans la zone de texte (pensez à valider avec entrée). Les nouvelles modalités sont automatiquement ajoutées à la base de données.

Vous pouvez aussi ajouter des variables et les éditer exactement comme dans la fenêtre de gestion de la base de données.

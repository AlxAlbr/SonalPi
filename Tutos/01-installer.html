1 - Installer Sonal

1.1 Installation

1.1.1 Télécharger l'exécutable

L'installation de la version la plus à jour se fait en allant sur sonal-info.com onglet téléchargement. https://sonal-info.com/téléchargement

1.1.2 Télécharger le code source

Mais vous pouvez aussi aller directement sur GitHub récupérer le code source ou des installateurs. https://github.com/AlxAlbr/SonalPi

1.2 Compatibilité

Il existe des installateurs pour macOS, Windows et Linux.

Certains systèmes d'exploitation connaissent des limitations de sécurité qu'il est possible de contourner, voir ce tutoriel pour installer Sonal sur MacOS, par exemple.

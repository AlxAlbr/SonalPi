Pseudonymiser les noms propres

Ajouter des pseudonymes

Sonal vous permet de remplacer les noms propres par des pseudonymes, sans effacer les données originales.

Pour ce faire, cliquez sur l'onglet « Pseudonymiser » dans la fenêtre d'édition.

Dans le mode pseudonymisation, lorsque vous sélectionnez des noms propres dans le texte, ceux-ci sont ajoutés dans la table d'anonymisation, mais vous pouvez aussi les saisir directement dans une zone de texte libre.

Après chaque ajout, vous pouvez taper entrée pour appliquer ou cliquer sur le bouton "Applioquer"

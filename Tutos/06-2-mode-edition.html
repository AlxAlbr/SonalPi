Corriger le texte (mode "Edition")

Le mode édition du texte est le mode par défaut de la fenêtre d'édition. Il permet de corriger le texte, de supprimer des passages, d'ajouter des passages manquants etc.

Dans la fenêtre d’édition, le mode édition du texte permet de corriger le texte sans être perturbé par les fonctionnalités avancées que propose Sonal.

Par exemple, vous pouvez sélectionner des passages sans qu’il vous soit proposé de les affecter à un locuteur, de les coder, etc.

Positionnez simplement votre curseur dans la zone d'édition, modifiez le texte, saisissez de nouveaux mots, etc.

Sonal vous demandera de confirmer vos modifications périodiquement (bouton vert en haut de page ou Entrée). Il n'est pas nécessaire de le faire à chaque modification mais il est recommandé de le faire régulièrement.

Ce panneau vous permet également d’avoir des informations sur les segments et de modifier si besoin leurs coordonnées temporelles. Cela peut-être utile pour éditer un fichier de sous-titres par exemple.
